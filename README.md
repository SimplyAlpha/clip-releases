# Clip releases

Downloads and the update feed for **Clip**, a more secure version of [Maccy](https://github.com/p0deje/Maccy) by Dreamkid LLC.

Clip encrypts your clipboard history with your password before saving it, so the history file is useless to anyone without the password.

- **Download:** the latest `Clip.dmg` is on the [Releases](../../releases/latest) page. Clip requires macOS 14 or later.
- **Updates:** Clip checks this repo once a day and asks before installing. Every update is signed, and Clip refuses any update that isn't.

The first time you open Clip, macOS may ask you to confirm it under System Settings → Privacy & Security → Open Anyway.
